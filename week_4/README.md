# 4주차 과제

> 챕터: Forensic  
> 사일로: 개발

과제 내용: 아래 기능을 포함한 파일 분석 도구 개발
- 프로세스 목록 조회: 현재 실행중인 프로세스 정보 출력 (PID, 프로세스명, 메모리 사용량, 실행 경로)
- 특정 프로세스 메모리 덤프: PID를 입력받아 해당 프로세스의 메모리를 파일로 저장
- 문자열 추출: 덤프 파일에서 ASKII/Unicode 문자열 추출, 최소 길이 지정 가능
- 키워드 검색: 특정 키워드 (password, token, key, etc)를 메모리에서 검색. 찾은 위치(오프셋)과 주변 문맥 출력

- 결과 출력 방식: JSON 또는 Html 리포트 형태. 발견된 문자열 중 의심스러운 부분은 하이라이트. 

> 제출 내용: 소스 코드, 실행 결과

제시된 과제 내용을 보고, 어떻게 구성해야 할지를 llm 도움을 받아서 먼저 단계를 쪼갰다. 

1) 프로세스 목록 조회
2) 메모리 덤프 기능
3) 문자열 추출 및 키워드 검색
4) 리포트 생성

순서로 구현해보면서 기능을 추가하기로 했다.
