과제 내용: 아래 기능을 포함한 파일 분석 도구 개발
- 프로세스 목록 조회: 현재 실행중인 프로세스 정보 출력 (PID, 프로세스명, 메모리 사용량, 실행 경로)

- 결과 출력 방식: JSON 또는 Html 리포트 형태. 발견된 문자열 중 의심스러운 부분은 하이라이트.

## 1. 프로세스 목록 조회 구현

먼저 프로세스 목록 조회를 구현하기 위해 사용해야하는 python 라이브러리를 찾아보았다. 
기본 내장 모듈인 `os` 등을 사용하는 걸 처음에 고려했지만, 찾아보면서 `psutil`이라는 외부 라이브러리를 사용하기로 했다. 

따라서 먼저 `pip install psutil`을 통해 해당 라이브러리를 설치했다. 

`psutil`을 사용하면 
- OS(Windows/Linux/macOS)에 상관없이 동일한 코드로 프로세스 정보를 가져올 수 있습니다.
- PID, 이름, 경로, 메모리 사용량 등을 아주 직관적인 메서드로 제공합니다.
- 실행 중인 모든 프로세스를 반복문(Iterator)으로 쉽게 순회할 수 있습니다.

라는 점에서 llm이 추천해줬다. 

해당 모듈을 이용해, 줄이 딱딱 맞도록 프로세스 목록을 읽어오게 먼저 `processManager.py`를 작성했다. 

## 2. 메모리 덤프 기능 구현

`psutil`을 통해 프로세스 정보는 쉽게 읽어올 수 있었지만, 실제로 사용되고 있는 메모리 내부 내용은 읽어올 수 없었다.
따라서 `Windows Api`를 직접 호출해와서 읽어야 했다. 파이썬에서는 `ctypes`를 이용하면 `WinAPI`를 사용할 수 있다. 

이때 사용해야 하는 함수는 `kernel32.dll`에 있는 다음 세 함수였다:
- `OpenProcess`: 특정 PID를 가진 프로세스의 문을 연다
- `VirtualQueryEx`: 해당 주소에 데이터가 있는지, 읽을 수 있는지 확인해볼 수 있는? 지도 역할을 한다고 한다
- `ReadProcessMemory`: 실제로 읽을 수 잇다고 확인된 영역의 데이터를 가져온다 

이를 gemini를 통해
```
graph TD
    A[사용자 입력: PID] --> B{OpenProcess 호출};
    B -- 성공 --> C[메모리 시작 주소 0번지 설정];
    B -- 실패 --> Z[접근 거부/종료];
    C --> D{VirtualQueryEx로 영역 정보 조회};
    D -- 더 이상 영역 없음 --> E[덤프 종료 및 파일 저장];
    D -- 영역 정보 획득 --> F{상태 확인: 사용중(MEM_COMMIT) 인가?};
    F -- No (빈 공간) --> G[다음 영역 주소로 이동];
    F -- Yes (데이터 있음) --> H[ReadProcessMemory로 데이터 읽기];
    H --> I[파일에 쓰기];
    I --> G;
    G --> D;
```
와 같은 흐름으로 구현하면 된다고 작성해주었고, 이에 맞춰서 구현해보기로 했다.
